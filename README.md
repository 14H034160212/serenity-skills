# serenity-skills

Two installable agent skills built around **Serenity ([@aleabitoreddit](https://x.com/aleabitoreddit))** — a public X trader and AI/semiconductor *supply-chain* analyst who traces hyperscaler capex into the overlooked upstream bottlenecks (optical/CPO, InP substrates, memory/HBM, AI power/grid, robotics/physical AI).

| Skill | What it is |
|---|---|
| `serenity-chokepoint-analysis` | An **original** six-step chokepoint-analysis framework (CN) — distilled, written, and structured by [@14H034160212](https://github.com/14H034160212). Five-dimension checklist + anti-thesis table + evidence tiering + position sizing. Market-agnostic (US / HK / A-share / crypto). |
| `serenity-aleabitoreddit` | The full distilled @aleabitoreddit lens — methodology, per-ticker track record, a 473-ticker universe, and the raw tweet archive. **Redistributed from the upstream project below, with attribution** (see [ATTRIBUTION.md](ATTRIBUTION.md)). |

## Install

```bash
# both skills
npx skills add 14H034160212/serenity-skills
```

Then trigger on questions about AI/semiconductor/optical/memory/power/neocloud
names, supply-chain bottleneck analysis, or "用 Serenity 方法分析 XXX".

## ⚠️ Decision-support only — not financial advice

These skills never trade and never place or cancel orders. Serenity's
self-reported returns are unverified and carry obvious survivorship/selection
bias; his names are volatile micro/small-caps. Use the lens to ask better
questions, not to copy trades.
